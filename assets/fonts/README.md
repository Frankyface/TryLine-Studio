# Bundled fonts

Barlow Condensed v13 and Inter v20 from the Google Fonts CSS API, downloaded
2026-09-14. The stylesheet in `styles/fonts.css` preserves Google's weight and
Unicode-range declarations and the original WOFF2 files, including extended
Latin and other supplied subsets. The only substitutions are same-origin URLs.

Source: https://fonts.googleapis.com/css2?family=Barlow+Condensed:wght@400;500;600;700&family=Inter:wght@400;500;600;700&display=swap

Both families use the SIL Open Font License. The corresponding licenses are
included here. Keep the files and declarations together when updating; verify
the screenshots, geometry and label-stress suite after any font update.
